A one-line robot pickup line — written to `/output/entry.txt` by a small TypeScript program.

> I'm built to lift 400 kilos, but you're the one thing I can't pick up — so I'm asking instead.

## Run it

```sh
node main.ts
```

This writes the single-line entry to `/output/entry.txt` (creating `/output` if needed). The program is deterministic: every run writes the exact same bytes.

## The gate

The gate requires `/output/entry.txt` to be UTF-8 text of 1–200 characters, not only whitespace, exactly one line. This entry is 94 characters, so it passes.
